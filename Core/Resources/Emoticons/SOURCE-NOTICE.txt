ClearKeyboard Emoticons resource notice — Build108

This directory contains a finite, offline catalog. It is not an official, complete
or current WeChat catalog, and it does not inject WeChat-private sticker objects.
The owner inserts the entry's exact text code. WeChat may render a recognized
code; other apps may keep the code as ordinary text. Current device/app behavior
has not been tested by Codex.

Additional content: 104 ordinary Unicode Emoji use the host system's font, not
redistributed Apple font artwork. 12 text/kaomoji entries preserve the original
keyboard choices and add ordinary text expressions. Four original text-sticker
actions retain fixed IDs and are routed by the owner to its previous copySticker
implementation; this catalog does not remove their full-access requirement.

Semantic/pinyin aliases, grouping and UI are ClearKeyboard additions. Derived
Latin search keys never change the selected source code or user's input case.
Suggestions are optional and appended after language choices. They never own
Space, Enter, an English first candidate, or a Chinese decoder recommendation.

Source review and static resource preparation only. No model inference,
business-algorithm execution, accuracy/speed tests, probes or device tests run.
